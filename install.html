⛳ 幹事キャディ ホーム画面への追加方法

ホーム画面に追加すると、アプリのように、アイコンからすぐ開けます。インストールは不要で、無料です。

先にご確認ください

LINEのトーク内のリンクから開くと、LINEの中の画面で開き、ホーム画面に追加できません。次のどちらかで、SafariまたはChromeで開き直してください。

  • 画面右上（または右下）の … / 共有 から「Safariで開く」「ブラウザで開く」を選ぶ
  • URLをコピーして、SafariまたはChromeに貼り付ける

📱 iPhone（Safari）

  1. Safariで https://golf.medicom.co.jp/ を開く
  2. 画面下の 共有（□に↑） ボタンをタップ
  3. メニューを下にスクロールして 「ホーム画面に追加」 をタップ（見当たらないときは「さらに表示」の中）
  4. 右上の 「追加」 をタップ
  5. ホーム画面にできた 「幹事キャディ」 のアイコンから開く
iPhoneは、Safariとホーム画面のアプリで、保存されるデータが別です。追加したあとは、アイコンから開いて、もう一度「LINEでログイン」を押してください。

🤖 Android（Chrome）

  1. Chromeで https://golf.medicom.co.jp/ を開く
  2. 右上の ⋮ をタップ
  3. 「アプリをインストール」 または 「ホーム画面に追加」 をタップ
  4. 確認の画面で 「インストール」（または「追加」）をタップ
  5. ホーム画面にできた 「幹事キャディ」 のアイコンから開く

🔑 はじめて使うとき

  1. 「LINEでログイン」をタップして、LINEのアカウントでログイン
  2. チームを作る（例：○○ゴルフ会 幹事チーム）
  3. コンペを作って、出欠フォームのURLを、参加者に送る
機種変更やブラウザのデータ削除をしても、同じLINEアカウントでログインすれば、チームが戻ります。

困ったときは

うまくいかないときは、画面のスクリーンショットを、送ってください。お問い合わせは、下のフォームからも送れます。
